🌌 Galactic

Predictive Input & Pathfinding Framework for Geometry Dash

Galactic is an experimental Geometry Dash mod designed to explore predictive input processing, movement tracking, and pathfinding, with a focus on Android64.

✨ Features

- 8 Game Modes: Support structure for Cube, Ship, Ball, UFO, Wave, Robot, Spider, and Swing.
- Dual-Player Support: Separate player profiles for Player 1 and Player 2.
- Customizable Settings: Individual timing profiles for each player and game mode.
- Input Processing: Records and processes button press and release events.
- Movement Tracking: Tracks player positions and velocity.
- Path Prediction: Projects possible future player positions using available movement data.
- Performance Options: Configurable prediction limits and processing budgets.

🔧 Configuration

Galactic includes configurable options for:

- Input buffering
- Pathfinding
- Dual-player support
- Prediction horizon
- Pathfinder processing budget
- Individual timing profiles for all eight game modes

Player 1 and Player 2 have separate profiles.

🚧 Development Status

Galactic is an experimental project under active development.

Prediction accuracy, mode-specific physics, obstacle detection, and collision warnings require further implementation and in-game testing. Features may behave differently depending on the game mode and environment.

📦 Installation

1. Download the Galactic ".geode" build.
2. Open the file using Geode on a compatible Android64 installation.
3. Enable Galactic in the Geode mod list.
4. Configure its available settings.

🎯 Project Goal

The goal of Galactic is to develop a customizable predictive input and pathfinding system for Geometry Dash, with support for all eight game modes and dual-player gameplay.
